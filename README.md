One deadpan weather forecast for a city that does not exist, written by a
small Node program for make.fun's "Deadpan Forecasts for Cities That Do
Not Exist" bounty. The program validates its line against the gate
(UTF-8, 1-160 characters, not only whitespace), writes it to
`/output/entry.txt`, sets mode 0644, and reads the file back to prove
the bytes on disk are exactly the line it meant to write.

## Run it

Needs Node 22.18 or later, which runs TypeScript directly:

```sh
node main.ts
```
